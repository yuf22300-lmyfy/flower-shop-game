# 废土花店日记 🌸

一款单文件、免安装、手机可玩的末日温情经营叙事游戏。

> 大水退去之后的第 7 年，你在一座空城的街角开了一家花店。
> 花要水，人要故事，而这座城市的秘密，藏在每天傍晚的日记里。

## 怎么玩

- 打开 [在线版](https://yuf22300-lmyfy.github.io/flower-shop-game/) 直接玩（手机浏览器也可以）
- 或下载 `index.html`，双击离线玩
- 进度自动保存在浏览器本地

## 玩法

- 🌱 种花、浇水、杂交 —— 14 种花，各有习性
- 🔧 捡零件猜用途 —— 猜对变宝物，猜错就消失
- 🤝 7 位常客各有心事，好感度会改变剧情
- 📝 傍晚写日记（得先有一支铅笔树结的铅笔）
- 🌙 暗线：8 条线索，3 个结局

## 说明

- 纯 HTML/CSS/JS，无任何依赖与联网请求
- 全部花枯萎之日，游戏结束 —— 也会解开这座城最后的谜
